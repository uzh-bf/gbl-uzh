## Approval summary

Oversized display images are copied unchanged into this statically exported website. This package reduces their dimensions and encoded sizes while retaining public filenames, composition, and legitimate downloads. It also adds a repository-owned Vercel ignored-build command that skips previews only for known unrelated game and test changes. Production, shared packages, configuration, manifests, unknown paths, and unavailable comparison history continue building.

Approval mode: executable batch. The user authorized this bounded cleanup, ordinary task-branch publication, and a draft PR. The terminal condition is a reviewed draft PR with measured local savings, applicable verification, and exact-commit hosted check status or explicit blockers. No deployed or billed storage savings are claimed.
