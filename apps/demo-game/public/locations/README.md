# Canton artwork sources

The existing AG, AI, BE, FR, GR, JU, TI and ZH coats of arms are retained unchanged. The assets below were retrieved from Wikimedia Commons on 2026-09-28. Each linked file page records its source, authorship and licensing.

Flags are separate square flag artwork, not crops of the shield-shaped coats of arms. The UI clips these flags to circles. Imports remove XML/DOCTYPE declarations and add a viewBox when absent; flags also receive centered square viewBoxes (trimming minor export-bound discrepancies) and 512px intrinsic dimensions. Artwork paths and colors are unchanged.

Commons marks these files as public domain. Its file pages also note that official insignia may have usage restrictions independent of copyright.
